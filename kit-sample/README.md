# My lazy-kali-ricer kit

Private. Holds what lazy-kali-ricer needs to put a fresh install back the way I like it.

| File | What |
|------|------|
| `tools.txt` | Packages, pipx tools and git repositories to install |
| `bookmarks.json` | Browser bookmarks |
| `extensions.txt` | Extra browser extensions |
| `tools/` | My own scripts and folders, a copy of `~/tools` |

Restore on a new machine: clone this repository to `~/lazy-kali-kit`, open
lazy-kali-ricer, go to the **Browsers & tools** tab.
